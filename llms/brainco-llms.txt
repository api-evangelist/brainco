# BrainCo

> BrainCo is a Harvard-innovation-lab-founded neurotechnology company building non-invasive brain-computer interface (BCI) hardware and the developer SDKs around it: wearable EEG headbands (Focus, Focus1, FocusCalm) for attention and stress biofeedback, the BrainRobotics neuroprosthetic hand, and the Revo family of dexterous robotic hands. BrainCo ships first-party device SDKs rather than a public REST API. Backed by IDG Capital. Sectors: healthcare, neurotech, robotics, education.

This llms.txt was generated by the API Evangelist enrichment pipeline from the BrainCo public developer surface and the apis.io catalog. BrainCo exposes SDKs over BLE/serial/CAN and native bindings; it does not publish an OpenAPI-described public HTTP API.

## Packages / SDKs

- [bc-revo3-sdk (PyPI)](https://pypi.org/project/bc-revo3-sdk/): Python SDK for the Revo3 21-DoF dexterous hand. `pip install bc-revo3-sdk`
- [crimson-sdk (npm)](https://www.npmjs.com/package/crimson-sdk): Node.js SDK for Crimson portable EEG devices. `npm install crimson-sdk`
- [brainco-hand-sdk (GitHub)](https://github.com/braincotech/brainco-hand-sdk): Revo1/Revo2 hand SDK (Python + C/C++); RS-485, CAN, CAN FD, EtherCAT, Protobuf. MIT.
- [brainco_hand_ros2 (GitHub)](https://github.com/braincotech/brainco_hand_ros2): ROS 2 integration for BrainCo dexterous hands. Apache-2.0.
- [crimson-sdk-prebuild (GitHub)](https://github.com/braincotech/crimson-sdk-prebuild): Prebuilt native libraries for the Crimson EEG SDK. MIT.
